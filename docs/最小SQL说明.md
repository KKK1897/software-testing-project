# 本项目需要理解的最小 SQL

业务库存、单据、商品、身份都优先通过ERP接口核对。没有做数据库调优，也不要求学习复杂联表统计。

实际用过的只读安全核对：

```sql
SELECT DATABASE(), @@datadir;
```

`DATABASE()`返回当前连接库名，`@@datadir`返回该MySQL实例数据目录。清理脚本必须确认库名是`jsh_erp_qa`、目录位于本项目`runtime/mysql-data`才允许继续；并不因为地址是localhost就认为一定安全。

初始化脚本还执行过`SELECT @@datadir`，目的相同。源码和日志中的SQL仅用于解释字段长度、库存小数精度、空列表查询和驱动兼容问题，不作为日常业务验收主要手段。

数据库初始化的CREATE DATABASE、CREATE USER、GRANT和官方建表导入由脚本完成，不属于日常测试查询，不需要你背诵。它们只用于独立新库。不要将这些命令复制到已有业务数据库执行；不要手工修改库存表来让接口断言通过。

你需要理解：查询结果是什么、为什么查询、连接是否是隔离库。复杂SQL、索引调优、执行计划分析不在本期范围。
