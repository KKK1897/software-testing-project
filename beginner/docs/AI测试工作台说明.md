# AI 辅助测试工作台

工作台只监听 `127.0.0.1:8765`，不会暴露给局域网。它把 AI 的职责收敛为“读资料、给候选、整理失败现场”，把执行权交给固定的 Pytest 测试集。

## 启动

在项目根目录执行：

```powershell
python -m beginner.ai_testing.server
```

浏览器打开 `http://127.0.0.1:8765`。

## 使用流程

1. 上传 `.txt`、`.md`、`.docx` 或可提取文字的 `.pdf`，单文件不超过 3 MB。
2. 默认以本地证据模式生成候选点。若主动勾选“调用已配置模型”，工作台会把提取出的文件文本和关联证据发送至已配置的模型服务生成建议，且自动补充本地资料来源。
3. 工作台将原文件和 `*.test-points.md` 保存至 `beginner/artifacts/ai/uploads/`，输出正常、异常、权限、幂等与并发候选点及本地资料来源。
4. 审核候选点，补齐接口、测试数据和断言；AI 候选点不等于已执行用例。
5. 点击“执行冒烟测试”或“执行回归测试”。两者都只允许运行代码中固定的 Pytest 路径，输出 JUnit XML 和日志到 `beginner/artifacts/ai/runs/`。

## 安全边界

- 默认完全本地运行，上传资料不会发送到模型服务；仅在你主动勾选模型开关后外发提取文本和关联证据。
- 页面不接受 shell 命令、测试路径或超时参数；避免通过 AI 或网页执行任意命令。
- 回归测试可能创建测试数据，需在已配置的隔离 jshERP 环境运行。
- PDF 扫描件需要先 OCR；没有 `pypdf` 的 Python 环境会提示改传 TXT、Markdown 或 Word。
