# 登录到收付款结算的完整业务闭环

日期：2026-10-15，Australia/Sydney。当前固定jshERP v3.5本地环境支持采购付款、销售收款、欠款及账户流水；本轮新增3条Python接口测试并实际执行。它们测试ERP内部账本，不连接银行、微信、支付宝或支付网关，也不发生真实扣款。

## 链路和预期

登录fixture先获取真实验证码、提交MD5密码、保存Token。每条用例新建唯一QA两仓一商品、供应商、客户和期初2000元的结算账户；默认账户、已有往来单位及其余额不参与本链路。

|步骤|业务变化|A仓/B仓|测试账户余额|欠款变化|
|---|---|---|---|---|
|期初|独立QA账户期初记账2000|0/0|2000|无|
|采购入库|100件×10元，单据保存|100/0|2000|应付1000|
|采购付款|付款单关联采购单，付款1000|100/0|1000|应付清零|
|仓库调拨|A向B调拨30件|70/30|1000|不变化|
|销售出库|B仓销售10件×15元|70/20|1000|应收150|
|部分收款|收款单关联销售单，先收60|70/20|1060|已收60、待收90|
|剩余收款|第二张收款单再收90|70/20|1150|应收清零|
|最终对账|核对6张单据、3条资金流水|70/20，总90|2000−1000＋60＋90＝1150|双方欠款列表均为空|

6张单据是采购、调拨、销售各1张，付款1张、收款2张。流水金额必须分别为−1000、＋60、＋90，对应逐笔余额1000、1060、1150。净现金流−850不等于亏损850；本轮未验证利润报表。

这比单纯检查HTTP200多验证了单据唯一、表头与明细、业务单关联、分次结算、剩余欠款、库存不被资金操作重复影响、账户余额与流水一致性。

## 真实接口和协议要点

|接口|用途|
|---|---|
|POST /account/add|创建独立QA结算账户，期初2000，不设置为默认|
|POST /accountHead/addAccountHeadAndDetail|新增关联业务单的付款/收款单|
|GET /accountHead/list|检查单据数量及唯一性|
|GET /accountHead/getDetailByNumber，参数billNo|核对资金单表头、账户、往来单位、金额|
|GET /accountItem/getDetailList，参数headerId|核对关联业务单号、应结/已结/本次金额|
|GET /depotHead/debtList|部分结算核对finishDebt/debt，全额结算应从欠款列表消失|
|GET /accountHead/getFinancialBillNoByBillId|核对业务单关联的资金单号；该版本SQL只返回billNo，id为null|
|GET /account/listWithBalance|核对期初和当前余额|
|GET /account/findAccountInOutList|核对资金流水数量、单号、正负金额和逐笔余额|

付款请求表头totalPrice/changeAmount传负数；明细eachAmount传正数，后端保存时转负。付款详情接口展示时又转成正数，账户流水仍显示负数。这是按固定源码MoneyOutModal及AccountItemService的真实协议处理，不把付款显示正数误认成收入。

明细通过billNumber关联采购/销售单；当前场景只在表头填写accountId，明细不重复填写同一accountId，避免在主表和明细两条账户统计路径重复记账。采购/销售原单changeAmount为0，表示未现付，后续资金单独立结算。

## 清理和边界

清理先只读SQL核验jsh_erp_qa及独立datadir；再验证账户ID/名称/serialNo/期初金额、两名往来单位ID/名称/类型、资金单ID/单号/金额/状态、关联业务单及每条商品条码。发现未登记资金单、额外流水、审核状态或归属变化时拒绝清理。

顺序是资金单→业务单→商品与仓库→独立结算账户与往来单位。资金单删除后先确认余额恢复期初；所有对象均经业务接口删除，不清库、不强制删除其他数据。基础库存manifest没有finance字段，仍按原逻辑处理。

未覆盖：外部支付成功/失败、支付回调验签/重放、退款、超额结算、不同单号重复结算、并发收付款幂等性、强制审核、银行对账和完整财务。顺序同号拒绝不等于并发幂等性通过。DEF-001/002/003历史风险和证据继续保留。

简历可在亲自掌握后写：“扩展采购付款、仓库调拨、销售分次收款业务闭环，核对6张单据、应收应付、账户余额及资金流水，并验证重复单号与失败回滚。”不要写成微信/支付宝支付全链路或生产资金系统验收。
